# Assignment 2: FER2013 Facial Expression Recognition

## 1. Project Overview

This project investigates facial expression recognition using Convolutional Neural Networks (CNNs) and the FER2013 dataset. Seven facial expression categories are classified: Angry, Disgust, Fear, Happy, Sad, Surprise, and Neutral.

Five CNN variants are implemented and compared to investigate the effects of different model configurations and techniques.

## 2. Dataset Structure

The FER2013 dataset is organised into training and testing directories.

```text
data/
├── train/
│   ├── angry/
│   ├── disgust/
│   ├── fear/
│   ├── happy/
│   ├── sad/
│   ├── surprise/
│   └── neutral/
│
└── test/
    ├── angry/
    ├── disgust/
    ├── fear/
    ├── happy/
    ├── sad/
    ├── surprise/
    └── neutral/
```

The exact training and testing datasets provided through DLE are used. The training dataset is divided into training and validation subsets using a stratified 80/20 split. The official test dataset is reserved for final evaluation.

## 3. Technologies and Libraries

- Python
- PyTorch

Install the required dependencies using:

```bash
python -m pip install -r requirements.txt
```

## 4. CNN Experiments

Five CNN variants are evaluated:

1. Baseline CNN
2. CNN with Dropout
3. CNN with Data Augmentation
4. CNN with Batch Normalisation
5. Wider CNN

The experiments compare model performance using validation accuracy and other evaluation metrics.

## 5. Training the Models

Run the following command from the project directory:

```bash
python train.py --epochs 10
```

The batch size can also be specified:

```bash
python train.py --epochs 10 --batch-size 64
```

## 6. Webcam Application

After completing model training, run:

```bash
python webcam.py
```

Press `q` to close the webcam application.

Camera footage should be recorded with appropriate consent.

## 7. Results and Evaluation

Experimental outputs are saved in the `results/` directory.

These include:

- Model checkpoints
- Training histories
- Validation metrics
- Confusion matrices
- Per-class precision and recall
- Final test evaluation metrics

The results are used to compare the five CNN variants and identify the best-performing model based on validation accuracy.

## 8. Important Notes

- The FER2013 dataset is not included in the source code.
- The required DLE-provided training and testing images must be placed in the appropriate directories.
- Experimental results must be generated by running the code. Results should not be fabricated.
- Facial expression predictions describe visible expression categories and do not establish a person's actual internal emotional state.
